# Источники для корпуса учебного регламента АССБ

Документ состоит из двух частей:
1. **Список источников** — единая нумерация по ГОСТ Р 7.0.100–2018. На эти номера ссылаются план корпуса и разделы по темам.
2. **Источники по темам корпуса** — какие источники использованы в каждом из 13 документов и какие сведения из них взяты.

Сокращение **ТЗ** означает техническое задание на работу. Цифры, которые есть только в ТЗ, отмечены «(ТЗ)».
