# Семантический поиск по технологическому регламенту приготовления товарных бензинов

Корпус документов для курсовой работы «Семантический поиск по технологическому регламенту приготовления товарных бензинов». Цель работы — прототип RAG-системы, которая по вопросу на естественном языке находит фрагменты регламента автоматизированной станции смешения бензинов (АССБ) Омского НПЗ и формирует ответ со ссылкой на источник.

Корпус — учебный аналог технологического регламента АССБ. Он составлен по открытым источникам: научно-технической литературе, выпускным работам ТПУ, публикациям об АССБ Омского НПЗ, государственным стандартам и нормативным документам.

## Разметка документов

Каждый документ начинается с YAML-шапки с полями `document`, `title`, `doc_id`, `topics` и `sources`. Поле `sources` содержит номера источников из [docs/sources.md](docs/sources.md).

Заголовок документа — `#`, разделы — `##` с номерами, подразделы — `###`.

Перед каждой таблицей и нумерованной процедурой стоит однострочный комментарий с метаданными в формате JSON для последующего чанкинга:

```markdown
<!-- chunk: {"type": "recipe", "product": "АИ-95", "components": ["риформат", "алкилат", "изомеризат"], "description": "Рецептура бензина АИ-95, % мас."} -->

Таблица 3.2 — Рецептура бензина АИ-95, % мас.

| Компонент | Доля, % мас. |
| --------- | ------------ |
```

| Поле          | Значения                                                                         |
| ------------- | -------------------------------------------------------------------------------- |
| `type`        | `text`, `recipe`, `equipment`, `norm`, `procedure`, `component`                  |
| `product`     | марка бензина: `АИ-92`, `АИ-95`, `АИ-98`, `АИ-100` и др.                         |
| `category`    | категория оборудования или темы: `резервуары`, `насосы`, `АСУ`, `присадки` и др. |
| `method`      | способ смешения: `поточное`, `циркуляционное`                                    |
| `description` | краткое текстовое описание блока                                                 |

Таблицы не прерываются текстом, поэтому при чанкинге каждую таблицу можно выделить в отдельный чанк целиком.

## Чанкинг

Скрипт [src/chunking.py](src/chunking.py) режет корпус на чанки и сохраняет их в `data/chunks.jsonl` (папка `data/` не хранится в git).

```bash
pip install -r requirements.txt
python -m src.chunking
python -m src.chunking --max-chars 1500 --overlap 200
```

Порядок нарезки:

1. Документ делится по заголовкам `##`/`###`, внутри раздела — по комментариям `<!-- chunk: ... -->`.
2. Каждая таблица — отдельный чанк вместе с подписью «Таблица N — ...». Таблица длиннее 2500 знаков делится по строкам с повтором шапки; глоссарий делится по одному сокращению на чанк.
3. Текст раздела дорезается рекурсивно: абзацы, затем строки списка, затем предложения; лимит 1500 знаков (около 400 токенов), перекрытие до 200 знаков по целым предложениям.
4. Вводная фраза с двоеточием не отрывается от списка или формулы, пояснение «где ...» — от формулы. Короткая фраза вида «приведены в таблице 4.2» присоединяется к своей таблице или процедуре.

Поля чанка:

| Поле | Содержание |
| --- | --- |
| `chunk_id` | `03-005`: номер документа и порядковый номер чанка |
| `doc_id`, `document`, `doc_title` | документ из YAML-шапки |
| `section`, `subsection`, `section_path` | раздел и подраздел |
| `chunk_type` | `text` или `table` |
| `block_type` | тип из разметки: `text`, `recipe`, `equipment`, `norm`, `procedure`, `component` |
| `grades` | марки бензина в чанке: АИ-92, АИ-95, АИ-98, АИ-100, Нормаль-80, газовый бензин (с учётом названий Регуляр-92, Премиум-95, Супер-98, G-Drive 100) |
| `category`, `method`, `components`, `description` | поля разметки `<!-- chunk -->` |
| `table_caption`, `part`, `parts_total` | подпись таблицы и номер части при делении |
| `topics`, `sources` | темы и номера источников документа |
| `text` | исходный фрагмент |
| `embed_text` | фрагмент с контекстом «документ > раздел» и подписью таблицы — подаётся в энкодер |
